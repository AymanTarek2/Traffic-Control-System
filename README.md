# Traffic Control System

## Overview

This project involves developing a highway traffic control system to manage traffic lights and detect red light violations. Led by a team of 10, the system integrates 220V traffic lights and ultrasonic sensors, implemented on the Basys3 FPGA platform using VHDL.

## Features

- **Traffic Light Control**: Manages 220V traffic lights for highway control.
- **Red Light Violation Detection**: Utilizes ultrasonic sensors to detect vehicles running red lights.
- **FPGA Implementation**: Developed using the Basys3 FPGA platform.
- **VHDL Programming**: Implemented in VHDL for hardware description and control.
